# Catatan rilis 1.3 (versionCode 3)

Teks untuk kolom "Release notes" di Play Console (maks. 500 karakter per bahasa). Ini rilis pertama di Google Play, jadi isinya menjelaskan aplikasi secara umum dan perubahan terbaru.

```
<id-ID>
Rilis pertama MySimoka SmartGrowth di Google Play.
• Catat tinggi, berat, dan imunisasi siswa per kelas, manual atau dengan alat ukur Bluetooth (opsional).
• Cek akurasi dan kalibrasi alat SmartGrowth dari aplikasi.
• Panduan izin Bluetooth dan tombol untuk menyalakan Bluetooth.
• Peringatan bila foto wajah belum terunggah saat registrasi wajah.
• Tombol kembali Android didukung untuk navigasi.
• Menu Profil → Pengaturan Akun: Kebijakan Privasi dan Hapus Akun.
</id-ID>
```

Sumber di riwayat git: `204357f` (cek akurasi/kalibrasi SmartGrowth), `dc44d49` (modal izin Bluetooth), `8ad5f14` (peringatan unggah wajah), `995c7df` (tombol back hardware), dan perubahan rilis Play (Pengaturan Akun, signing, izin).
